# Code comments

Load on request before writing comments or docs.

**Rule**: Terse, purposeful comments; let the code document itself.

- Document a function in one or two sentences max unless more is genuinely needed. Don't over-explain or comment line-by-line unless the code is complex.
- Prefer a single-line comment above only the critical steps.

Rust-specific rustdoc conventions live in the rust-implementation skill.
